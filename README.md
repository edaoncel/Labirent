🌀 Labirent Oyunu (C#)



Bu proje, kullanıcının dikkat ve hız becerilerini test eden, C# ve Windows Forms kullanılarak geliştirilmiş bir labirent oyunudur. Proje, nesne etkileşimleri ve koordinat takibi gibi temel oyun programlama mantıklarını içerir.





🧱 Duvar Çarpışma Kontrolü: Farenin veya karakterin duvarlara değip değmediğini anlık olarak kontrol eden algoritma.

🏁 Bitiş Noktası Mantığı: Hedefe ulaşıldığında tetiklenen tebrik mesajı ve seviye tamamlama mekanizması.

🔄 Otomatik Reset: Duvara çarpıldığında oyuncuyu başlangıç noktasına döndüren dinamik yapı.

🎨 Görsel Tasarım: Windows Forms bileşenleri ile oluşturulmuş, kullanıcıyı odaklayan labirent haritası.





🛠️ Teknolojiler ve Araçlar

Dil: C# (.NET Framework)

Arayüz: Windows Forms (WinForms)

Geliştirme Ortamı: Visual Studio

Temel Konseptler: Event Handlers (Mouse/Key Events), Collision Detection, Koordinat Yönetimi.

🚀 Nasıl Çalıştırılır?



1. Projeyi İndirin: Depoyu klonlayın veya ZIP olarak bilgisayarınıza kaydedin.

2. Visual Studio ile Açın: Klasör içindeki `.sln` veya `.csproj` dosyasını Visual Studio ile çalıştırın.

3. Başlatın: `F5` tuşuna basarak veya `Start` butonuna tıklayarak oyunu başlatabilirsiniz.

4. Hızlı Erişim: Derleme sonrası `bin/Debug` klasöründeki `.exe` dosyası ile doğrudan oynayabilirsiniz.
